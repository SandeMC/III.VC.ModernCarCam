# SACarCam with Modern Drive-By & Camera Tilt/Wobble

Fork of [SACarCamWithModernDriveBy](https://github.com/ICantReadYourMind/SACarCamWithModernDriveBy).

This fork restores the authentic vehicle camera wobble (steering roll and inertia tilt physics via `WellBufferMe`) from vanilla GTA Vice City and GTA III when the camera is not being manually moved with the mouse or analog stick.
